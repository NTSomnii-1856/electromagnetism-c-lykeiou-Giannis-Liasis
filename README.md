# Ηλεκτρομαγνητισμός Γ΄ Λυκείου

Διαδραστικό μάθημα στα ελληνικά · Giannis Liasis.

## Το μάθημα

[Άνοιγμα του μαθήματος](https://ntsomnii-1856.github.io/electromagnetism-c-lykeiou-Giannis-Liasis/)

14 ενότητες, διαδραστικά πειράματα και οι 20 τελικές ασκήσεις του βιβλίου με αναλυτικές λύσεις. Λειτουργεί σε υπολογιστή, tablet και κινητό, χωρίς λογαριασμό μαθητή. Οι προσωπικές σημειώσεις αποθηκεύονται μόνο στον browser του μαθητή.

## Υλικό αναφοράς

Φυσική Γ΄ Λυκείου Προσανατολισμού, Κεφάλαιο 4: Ηλεκτρομαγνητισμός, Υπουργείο Παιδείας Κύπρου, Β΄ έκδοση 2020, και σημειώσεις μαθήματος. Τα σχήματα του βιβλίου διατηρούν την αναφορά στην αρχική εικόνα και σελίδα. Οι λύσεις και οι διαδραστικές δραστηριότητες έχουν συνταχθεί για το μάθημα.

## Φιλοξενία και ενημερώσεις

GitHub Pages, από τη ρίζα του κλάδου `main`. Το `index.html` περιέχει όλο το μάθημα και τα σχήματα. Για ενημέρωση, αντικαταστήστε αυτό το αρχείο και κάντε commit στο `main`.
