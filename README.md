# Ηλεκτρομαγνητισμός Γ΄ Λυκείου

Σύντομες σημειώσεις στα ελληνικά · Γιάννης Λιασής.

## Το μάθημα

[Άνοιγμα του μαθήματος](https://ntsomnii-1856.github.io/electromagnetism-c-lykeiou-Giannis-Liasis/)

Ένα θέμα κάθε φορά, ορισμοί, σχήματα, παραδείγματα με εκφωνήσεις και λύσεις. Οι τρεις περιπτώσεις του κινούμενου πλαισίου παρουσιάζονται μαζί, με τα αντίστοιχα διαγράμματα κάτω από καθεμία. Η αμοιβαία επαγωγή προηγείται του μετασχηματιστή.

Οι 20 ασκήσεις με τις λύσεις τους βρίσκονται σε ξεχωριστή σελίδα. Το μάθημα λειτουργεί σε υπολογιστή, tablet και κινητό, χωρίς λογαριασμό μαθητή.

## Φιλοξενία και ενημερώσεις

GitHub Pages, από τη ρίζα του κλάδου `main`. Το `index.html` περιέχει τη θεωρία και τα σχήματα. Το `electromagnetism-greek-exercises.html` περιέχει τις ασκήσεις και τις λύσεις. Για ενημέρωση, αντικαταστήστε τα δύο αρχεία και κάντε commit στο `main`.
